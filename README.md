# Portfólio Profissional — Anna Luiza Pereira Silva

> Projeto desenvolvido em **React (JSX)** + **Vite** para apresentação acadêmica e profissional da trajetória, projetos e habilidades de **Anna Luiza Pereira Silva**, estudante do 2º período de Engenharia de Software na PUC Minas.

---

## 📌 Visão Geral do Sistema
Este website apresenta minha formação acadêmica em Engenharia de Software na PUC Minas, a linha do tempo cronológica dos projetos desenvolvidos no GitHub, habilidades técnicas e canais diretos de contato com design minimalista em **preto e dourado**, suporte bilíngue (Português/Inglês) e animações suaves ao rolar a página.

## 🚀 Tecnologias Utilizadas

### Front-End
- **React 19 (JSX)**: Biblioteca para construção de interfaces reativas baseadas em componentes.
- **JavaScript (ES6+)**: Linguagem principal de desenvolvimento dos componentes e lógica.
- **Vite 8**: Ferramenta de build rápida e servidor de desenvolvimento.
- **Tailwind CSS 4**: Estilização utilitária com paleta em preto e dourado.
- **Motion (Framer Motion)**: Animações suaves de entrada e rolagem.
- **Lucide React**: Conjunto de ícones vetoriais em SVG.

### Hospedagem Gratuita em Nuvem
- Preparado para deploy gratuito em nuvem na **Vercel**, **Render** ou **GitHub Pages**.
